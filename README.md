
# EduTrack

EduTrack is a student management system designed for schools. Users can create accounts, but only an admin can activate them. Admins have full control—they can approve users, manage passwords, and register or edit student details. Teachers can view student info, update grades, and record attendance. Students can log in to view their own profile, grades, GPA, and change their password. EduTrack helps keep school records organized and easy to manage.
